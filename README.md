# Predictive-Maintenance-IoT-Telemetry-System
A machine learning-based predictive maintenance application designed to monitor equipment health and identify potential machinery failures using IoT sensor telemetry data.

The project processes operational sensor readings, applies machine learning classification, and provides an interactive dashboard for monitoring equipment conditions and predicting failure risks.

**Key Features:**
- Developed an automated telemetry pipeline to ingest, clean, and store 1,000+ sensor reading events.
- Processed operational parameters, including vibration, temperature, and RPM.
- Used SQLite for structured storage and management of sensor telemetry data.
- Implemented a Random Forest Classifier using Scikit-Learn to predict potential equipment failure risks.
- Developed an interactive Streamlit dashboard displaying failure probability predictions and anomaly alerts.
- Integrated data processing and machine learning workflows to support equipment health monitoring.

**Technologies Used:** Python, Scikit-Learn, SQLite, Streamlit, Pandas, Random Forest.

**Objective:** To demonstrate how machine learning and IoT telemetry data can be utilized for predictive maintenance, helping identify potential equipment failures before they occur.
